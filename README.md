# JDBC Learning 🚀

A **fresher-friendly, step-by-step JDBC course** with Java code, SQL, Hinglish comments, practice tasks, and interview questions.

## 🎯 Goal
By completing this repository, you should understand how a Java application communicates with a relational database using JDBC and how JDBC concepts lead into Spring `JdbcTemplate` and JPA/Hibernate.

## 📚 Learning Roadmap

| # | Topic |
|---|---|
| 00 | Setup: Java + MySQL + JDBC Driver |
| 01 | JDBC Introduction |
| 02 | JDBC Architecture |
| 03 | JDBC Driver |
| 04 | Connection |
| 05 | Statement |
| 06 | PreparedStatement ⭐ |
| 07 | ResultSet |
| 08 | CRUD Operations |
| 09 | Transactions |
| 10 | JDBC Exception Handling |
| 11 | DAO Pattern |
| 12 | Mini JDBC Project |
| 13 | JDBC → Spring JdbcTemplate → JPA/Hibernate |

## 🧠 Recommended Order
Study each folder from **00 → 13**. Run the examples yourself instead of only reading them.

## 🔑 Prerequisites
- Core Java basics
- OOP basics
- Basic SQL: `CREATE`, `INSERT`, `SELECT`, `UPDATE`, `DELETE`

## 💡 Teaching Style
Every example aims to answer four questions:
1. What is it?
2. Why do we need it?
3. How does the code work?
4. Where is it used in a real application?

## ⚠️ Important
Never hard-code real production database passwords in source code. For learning examples, use local credentials and prefer environment variables/configuration in real projects.

Happy Learning! ☕
